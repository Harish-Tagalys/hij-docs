HIJ offers two integration paths. Both use the same catalog, merchandising and analytics.

| | Storefront API | JS SDKs |
| --- | --- | --- |
| What it is | REST API, `GET https://api.hij-search.example/v2/...` | Browser scripts: full stack (`HIJ.UIWidgets.*`) or headless (`HIJ.Connector.*`) |
| Runs | Anywhere: server, app, edge function | In the browser only |
| Renders UI | No | Full stack: yes, templatable widgets. Headless: no, you render. |
| Keeps request state (filters, sort, page) | No, you build each request | Yes |
| Sends analytics | No. You send every event. | Search, suggestion, collection and widget events |
| Versions | v2 | Full stack 3.x and 2.x, headless 3.x and 2.x |

## Decision table

| Your store | Path | Store-event analytics |
| --- | --- | --- |
| Liquid theme, ready-made UI | [Full stack](/full-stack/quick-start) | [Shopify Pixel](/analytics/shopify-pixel) (automatic) |
| Liquid theme, your own UI | [Headless](/headless/quick-start) | [Shopify Pixel](/analytics/shopify-pixel) (automatic) |
| Hydrogen/Oxygen, results rendered in the browser | [Headless](/headless/quick-start) | [SDK manual analytics](/analytics/sdk-manual) |
| Hydrogen/Oxygen, results in server-rendered HTML | [Storefront API](/storefront-api/overview) | [Analytics API](/analytics/analytics-api) |
| Other custom front end (Remix, Next.js, Vue) | [Headless](/headless/quick-start), or [full stack](/full-stack/quick-start) for ready-made widgets | [SDK manual analytics](/analytics/sdk-manual) or the [GTM template](/analytics/gtm/setup) |
| Native app or backend job | [Storefront API](/storefront-api/overview) | [Analytics API](/analytics/analytics-api) |

<Callout kind="tip">
You can mix paths. A Hydrogen store can render collection pages on the server with the Storefront API and use the headless SDK for search suggestions in the browser. Send each event once, from the place that knows about it.
</Callout>

## Why analytics matter on every path

HIJ ranks results with shopper behaviour: views, clicks, add to cart and orders. Without these events, results fall back to catalog order and the dashboard reports stay empty. The [analytics overview](/analytics/overview) shows which events each path sends for you and which ones you send yourself.

## Server-side SDK

The JS SDKs don't run in Node.js or other server runtimes. A server-side SDK is planned. See [server-side SDK](/sdks/server-side).
