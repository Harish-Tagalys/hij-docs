HIJ Search adds product search, search suggestions and merchandised collections to an online store. Pick the product that matches how your store is built. Each product is versioned on its own, so the version menu inside a product only changes that product's pages.

| Product | Namespace or interface | Best for | Current version |
| --- | --- | --- | --- |
| [Full stack](/full-stack/quick-start) | `HIJ.UIWidgets.*` | Themes that want ready-made, templatable widgets | 3.0.20 |
| [Headless](/headless/quick-start) | `HIJ.Connector.*` | Custom front ends that render their own UI | 3.0.21 |
| [Storefront API](/storefront-api/overview) | `GET https://api.hij-search.example/v2/...` | Server-side rendering and native apps | v2 |
| [A/B testing](/ab-testing/setup-liquid) | Liquid snippet and library | Testing collection merchandising in a Liquid theme | |
| [Google Tag Manager](/gtm/setup) | GTM tag template | Sending analytics events from your data layer | |
