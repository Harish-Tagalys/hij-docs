## Configure the fallback

Set `catalogFeed` in the platform configuration (see the [quick start](/full-stack/quick-start)). No other change is needed: the widget switches automatically and switches back on the next page load.

| Trigger | Falls back? |
| --- | --- |
| Network error or timeout (5 seconds) | Yes |
| `5xx` response | Yes |
| `429` rate limit | Yes |
| Other `4xx` responses | No. `onFailure` is called instead. |
