HIJ Search adds product search, search suggestions, merchandised collections and recommendations to a Shopify store. Every integration follows the same steps:

<Steps>
  <Step title="Install the HIJ Search app">
    Install the app from the Shopify App Store and let the first catalog sync finish. See [install the app](/get-started/install-app).
  </Step>
  <Step title="Collect your credentials">
    Copy your shop ID and storefront token. See [credentials](/get-started/credentials).
  </Step>
  <Step title="Choose your path">
    Call the [Storefront API](/storefront-api/overview) directly, or load a [JS SDK](/sdks/overview): full stack (ready-made widgets) or headless (your own UI). Use the chooser below.
  </Step>
  <Step title="Send analytics">
    Analytics drive ranking, personalisation and reports. Which events you send yourself depends on your store type. See the [analytics overview](/analytics/overview).
  </Step>
  <Step title="Verify, then extend">
    Run the [verification checklist](/get-started/verify), then add [A/B testing](/ab-testing/overview), [checkout recommendations](/checkout-recommendations/overview) and [recipes](/recipes/index).
  </Step>
</Steps>

## Choose your path

Answer three questions about your store to get a recommended path and analytics method.

<PathChooser />

The same recommendations as a table:

| Liquid theme? | Own UI? | Server-side rendering? | Path | Store-event analytics | Start here |
| --- | --- | --- | --- | --- | --- |
| Yes | No | No | Full stack (UI widgets SDK {{UI_WIDGETS_VERSION}}) | [Shopify Pixel](/analytics/shopify-pixel), automatic | [Full stack quick start](/full-stack/quick-start) |
| Yes | Yes | No | Headless (Connector SDK {{CONNECTOR_VERSION}}) | [Shopify Pixel](/analytics/shopify-pixel), automatic | [Headless quick start](/headless/quick-start) |
| Yes | Either | Yes | Storefront API v2 | [Shopify Pixel](/analytics/shopify-pixel) for store events, [Analytics API](/analytics/analytics-api) for search and click events | [Storefront API overview](/storefront-api/overview) |
| No | No | No | Full stack (UI widgets SDK {{UI_WIDGETS_VERSION}}) | [SDK manual analytics](/analytics/sdk-manual) or the [GTM template](/analytics/gtm/setup) | [Full stack quick start](/full-stack/quick-start) |
| No | Yes | No | Headless (Connector SDK {{CONNECTOR_VERSION}}) | [SDK manual analytics](/analytics/sdk-manual) or the [GTM template](/analytics/gtm/setup) | [Headless quick start](/headless/quick-start) |
| No | Either | Yes | Storefront API v2 | [Analytics API](/analytics/analytics-api) for every event | [Storefront API overview](/storefront-api/overview) |

On both SDK paths the SDK itself sends search, suggestion, collection and widget events. "Store-event analytics" covers the rest: product views, add to cart, checkout and orders. The [choose your path](/get-started/choose-your-path) page explains each row.

<Note>
Hydrogen storefronts render on the server, but that alone doesn't mean "server-side rendering" here. Answer **yes** only if HIJ results must be in the server-rendered HTML. Client-side search and collection UI inside a Hydrogen app uses the headless SDK.
</Note>
