The HIJ tag template sends shopper events to the HIJ analytics API from Google Tag Manager. This page covers template release **r20240718**.

## Install the template

1. In GTM, open **Templates → Tag templates** and select **HIJ Search Analytics**.
2. Under **Template details**, check that the release is `r20240718`.
3. Create a new tag of type **HIJ Search Analytics**.

## Configure the tag

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `hijShopId` | Variable | Yes | Your shop ID. Create a constant variable named `hijShopId` and select it here. Later releases rename it to `hijStoreId`. |
| `publicKey` | Text | Yes | Your public storefront token from **Settings → Credentials**. |
| `apiVersion` | Locked | | Always `v1`. Events are sent to `https://api.hij-search.example/v1/track`. |

This release has no `consentMode` or `marketCode` field.

## Map data layer events

Release r20240718 sends the v1 analytics API event set, which uses different event names.

| Data layer event | HIJ event (API v1) | Required data layer fields |
| --- | --- | --- |
| `view_item` | `view_product` | `ecommerce.items[0].item_id` |
| `add_to_cart` | `add_to_cart` | `ecommerce.items[]` with `item_id`, `quantity` |
| `search` | `search` | `search_term` |
| `purchase` | `purchase` | `ecommerce.transaction_id`, `ecommerce.items[]` |

Product clicks and collection views aren't sent by this release.

## Consent

Block the tag until the shopper consents: open **Advanced settings → Consent settings**, select **Require additional consent for tag to fire** and add `analytics_storage`.

## Upgrading

| r20240718 | Current release |
| --- | --- |
| `hijShopId` variable | `hijStoreId` variable |
| `publicKey` | `storefrontToken` |
| v1 events (`view_product`, `search`, ...) | v2 events (`product_viewed`, `search_performed`, ...) |
| Consent settings on the tag | `consentMode` field |
